# Air.mux v0.5.17

配置库按实际改动确认关联方案，减少重复确认。

## 本次改动

- 未修改内容时保存直接结束，不增加配置、节点或方案版本。仅修改配置名称、用途说明或规则说明时直接保存，不要求关联方案重新确认。
- 配置库和方案内的“编辑配置”共用新的影响面板。按实际变化自动定位分区，集中展示受影响方案，支持一次确认；需要调整的方案可单独处理。
- 覆盖节点、地区与分组、规则集、路由、解析地址、DNS、Fake IP、独立入站、运行与记忆、TUN、嗅探，以及 Loon 的连接与绕过设置。
- 保留各方案已有成员、独立选择及相对顺序。新增排序项先展示候选位置，用户统一接受或单独调整；局部取消不覆盖其他设置。
- 跟踪规则正文、解析地址、节点复用和失效出口的间接影响。未使用的解析地址及被方案独立设置覆盖的默认值，不要求无关方案重确认。
- 保存时重新检查影响范围和依赖版本，缺少确认、冲突未解决、预检失败或发生并发修改时不提交。配置、节点与必要方案继续原子保存。
- 修正安装模板和公共说明中的默认镜像版本，统一指向本次发行。

## 升级说明

- 镜像 `docker.io/jaelinker/airmux:v0.5.17`，平台 `linux/amd64`。固定摘要和源码提交见发行附件。
- 无新增 SQL，沿用十四份不可变迁移。从 `0.5.16` 升级保留节点、配置、方案、访问链接和引导状态，数据库代际仍为 `plan-local-v1`。
- 最低升级版本为 `0.5.0`。**从 `0.5.9` 之前的版本升级仍会执行 `0.5.9` 引入的清理迁移，删除旧公共方案、客户端方案、相关归档及全部访问链接，不迁移或兼容旧方案。** 账号、来源、节点、管理员基础资料及系统配置保留。升级前备份数据库并保管原加密主密钥；旧 `0.4.x` 须独立空库安装。

## 验证范围

- 本地功能验证：Rust 135 项、隔离 PostgreSQL 38 项、前端 326 项及 Python 55 项通过；格式、契约、类型检查及正式和原型构建通过。
- 浏览器验证无修改保存、说明修改、两个配置编辑入口、局部排序与统一保存；1280px 和 640px 无页面横向溢出。保存后重读保留各方案不同顺序。
- 四份实际生成配置通过 Mihomo v1.19.33 原生校验。Loon 原生与实机验证继续暂缓，未验证真实代理流量。
- 最终镜像三文件空库安装、默认七个地区、首次管理员改密、真实接口保存重读与生成通过；镜像版本、源码、架构及十四份 SQL 摘要一致。
- 从正式 0.5.16 的正常升级与迁移退出码 42 故障演练通过，33 张业务表完整字段摘要及十四份迁移保持。两份自动备份均以原密钥和旧镜像恢复至独立库，真实 HTTP 可读取 35 个节点及方案并生成配置。
- 空库、升级与两份恢复环境的 12 份实际生成配置通过 Mihomo v1.19.33 原生校验。
