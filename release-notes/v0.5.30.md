# Air.mux v0.5.30

方案替换为不同基础配置时，自动重置手动组的地区关联，不再要求先手动清除旧地区引用。

- 清除旧地区的选择及排除记录。自动纳入开启的组按新基础配置建立地区关联；关闭的组不自动选中地区。
- 继续复用的手动组保留直选节点、DIRECT/REJECT 设置和相对顺序。重新选择同一基础配置或普通刷新时不重置。
- 替换先在独立草稿完成读取、成员重建和预检，成功后一次性更新页面。失败保留原方案及选择抽屉，保存方案后才生效。

## 升级说明

从 0.5.29 升级无新增 SQL 迁移，沿用十五份历史迁移。自动重置发生在编辑器明确替换基础配置时，不批量重写已保存方案。

从 0.5.27 或更早版本升级仍会执行功能 DNS 的第十五份迁移，须保留原加密主密钥，且被引用的基础 DNS 来源必须完整、无歧义。升级前请备份数据库。

最低升级版本为 0.5.0。**从 0.5.9 之前升级会执行历史清理迁移，删除旧公共方案、客户端方案、相关归档及全部访问链接。** 0.4.x 须独立空库安装。Loon 原生与实机验收继续暂缓。
