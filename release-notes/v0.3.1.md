Airmux RS v0.3.1 — DNS 策略优先级与网络出站 / DNS priority and network outbounds

### 更新内容

- 修复 Mihomo DNS 策略按字段名排序的问题，按用户启用策略顺序生成；完整配置与脱敏预览顺序一致。
- 常规 DNS 解析可选择直连、默认组、指定组或遵守路由规则；专项策略保持独立出站。
- 远程规则集支持明确选择下载与更新出站，不依赖业务路由的分类规则选择下载代理。
- 新出站使用稳定的组引用，支持复制、模板应用与分组改名；失效引用、出站冲突和不兼容的 Loon 设置会在预览中提示。
- 不自动改变旧方案的出站。重新生成后 DNS 顺序按草稿恢复，需要重新预览、发布并更新客户端。

### 升级说明

无新增数据库迁移，保留现有数据库、配置及加密密钥。发布镜像可用后按正常升级流程同时更新 api、frontend、updater。手动升级使用 `AIRMUX_VERSION=v0.3.1`；若固定了镜像摘要，应采用本版本实际发布的摘要。构建与发布完成前不得使用占位摘要。

### Changes

- Preserve user-defined DNS policy priority in Mihomo YAML and redacted previews instead of sorting by keys.
- Configure default DNS upstream connections through DIRECT, the default group, a specific group, or routing rules. Specific DNS policies keep their own outbounds.
- Choose explicit rule-provider download and update outbounds independently of traffic routing.
- Preserve stable group references through copying, template application, and renaming. Preview validation catches invalid references, conflicting settings, and unsupported Loon options.
- Existing outbound defaults remain unchanged. Regenerate, preview, publish, and refresh clients to apply corrected policy order.

No new database migration is required. Preserve the configuration and encryption key, and update api, frontend, and updater together once release images are published.
