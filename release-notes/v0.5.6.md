# Airmux RS v0.5.6

策略解析器采用已确认的两步交互：先批量添加规则集或域名，再统一排序全部匹配。同批加入的条目可以分散排列，并保留各自的 DNS 与出口。

## 策略维护

- Mihomo 域名解析策略和节点服务器解析策略共用同一流程。第一步每批选择公共 DNS 和指定出口，支持多行域名与规则集多选；证书、ECS 等附加参数保持折叠。
- 第二步将所有批次的规则集和域名放在同一列表，通过前置手柄拖动或上下方向键调整顺序。返回添加、应用后重开保留交错顺序；新增匹配追加到全局末尾。
- 保留已有策略标识、解析器身份及显式 false、空值和附加参数。取消不改变外层方案；应用更新页面草稿，保存方案后生效。
- 指定出口直接展示，共享解析器字段避免重复维护。本任务抽屉最多 780px，窄窗口自动单列，修正展开参数时控件覆盖问题。
- 失效规则引用保留并提示修正；应用前检查缺失选择、重复启用匹配及 DNS 类型范围，保存错误可定位到共享批次中的对应参数。

## 安装与升级

- 镜像为 `docker.io/jaelinker/airmux:v0.5.6`，支持 `linux/amd64`；固定摘要及实际源码提交见发行清单。
- 最低可升级版本为 **0.5.0**，数据库代际为 `plan-local-v1`。本版不改变接口或存储字段，没有新增迁移，十二份已发布 SQL 保持不变。
- 升级保留原程序加密主密钥、数据库、SSH 主机记录和更新器状态。旧 `0.4.x` 仍需独立空库安装，失败时按部署指南保留备份和现场。
