# Airmux RS v0.5.8

Mihomo 客户端方案新增独立 Mixed 入站，可为应用设置专用代理端口和固定节点或分组。

## 独立入站

- 在客户端方案的「运行与记忆 → 独立入站监听」管理多个入口，支持独立收缩、启停、IPv4 / IPv6 地址、端口及 SOCKS5 UDP。
- 固定出口可选择当前公共方案的节点或分组，也可选择遵循方案路由。应用需主动连接该入口端口，不按应用名称自动分流。
- 出口使用稳定标识，改名后生成当前名称。无效节点、失效分组或空分组明确阻断生成，不自动回退直连。
- 前后端校验名称、地址、端口占用和出口引用。取消保留外层方案，应用后仍需保存客户端方案。
- 来源覆盖、来源删除及手动节点删除时，在同一事务清理依赖入口并更新客户端版本。
- 立即重启提交和等待重启期间，单个加载圈替换电源图标，避免两个图标同时出现。

## 安装与升级

- 镜像 `docker.io/jaelinker/airmux:v0.5.8`，支持 `linux/amd64`。固定摘要和实际源码提交见发行清单。
- 最低可升级版本 **0.5.0**，数据库代际 `plan-local-v1`。没有新增迁移，十二份已发布 SQL 不变，旧客户端方案缺少入站配置时保持空列表。
- 保留原加密主密钥、数据库和更新器状态。旧 `0.4.x` 仍需独立空库安装。
