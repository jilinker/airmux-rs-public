Airmux RS v0.4.3 — 方案规则集批量操作 / Batch rule-set configuration

### 更新内容

- 方案及方案模板的规则集配置新增「从规则集管理导入」：支持搜索、行为筛选、多选和全选当前结果，跨筛选保留选择。跳过已添加、已归档及尚无有效内容的条目。
- 导入追加库引用，行为和格式跟随管理配置，同名自动添加数字后缀。客户端下载间隔默认 86,400 秒，下载出站使用客户端默认；原有设置及路由、DNS 顺序保持。
- 新增批量删除与统一确认。路由或 DNS 引用中的规则集禁止选择，停用的引用也受保护；确认期间所选条目被移除、重命名或新增引用时整批取消。仅移除当前方案或模板中的引用，管理库原内容保留。
- 复用现有编辑器、弹窗、可搜索下拉和反馈组件，补充桌面及手机布局；单项操作和排序继续保留。

### 升级说明

本版本无需新增数据库迁移，保留现有 32 个迁移及数据库、管理员和加密密钥。方案修改沿用草稿自动保存、预览与发布流程；规则集管理仍提供当前有效内容。

### Changes

- Add filtered multi-select import from the rule-set library to plans and plan templates. Keep selections across searches and behavior filters; exclude existing, archived and unavailable entries.
- Append library references with matching behavior and format, unique names, a default client interval of 86,400 seconds and the client's default download outbound. Preserve existing settings and route/DNS ordering.
- Add confirmed batch removal with reference protection, including disabled routing and DNS policies. Cancel the entire batch if selected entries are removed, renamed or newly referenced before confirmation. Keep the original library contents.
- Reuse the shared editor, dialogs, searchable select and feedback components, with desktop and mobile layouts.

No new database migration is required. Preserve all 32 existing migrations, your database, administrator and encryption key.
