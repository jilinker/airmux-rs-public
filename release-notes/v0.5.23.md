# Air.mux v0.5.23

## 系统更新

- 检查更新时，加载圈替换刷新图标，检查结束后恢复。
- 主窗口只展示当前操作。点击底部「更新记录」可查看最近五次更新的状态和日志，最新记录排在最前。
- 发布说明按 Markdown 展示，支持标题、列表、链接、代码块和表格。
- 下载开始后仍可阅读对应版本的说明，后续进度刷新保留正文。

## 升级说明

从 0.5.22 升级无新增 SQL。请按部署指南配套更新 updater，使重新打开页面时也能读取下载任务保存的发行说明。应用在线升级不会自动重建 updater。

最低升级版本为 0.5.0。**从 0.5.9 之前升级会执行清理迁移，删除旧公共方案、客户端方案、相关归档及全部访问链接。** 升级前请备份数据库并保管原加密主密钥。0.4.x 须独立空库安装。
