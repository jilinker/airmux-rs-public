Airmux RS v0.4.6 — 订阅源 UA 与请求头编辑 / Subscription UA and request headers

### 更新内容

- 修复订阅源保存 UA 后，再次编辑不回显的问题。
- UA 改为现有可搜索下拉，支持服务器默认、Clash、Clash.Meta；已有其他 UA 保留为选项。旧请求头中的 User-Agent 会统一展示在 UA 控件。
- 其他请求头按 Key/Value 逐行新增、修改、删除，保存后重新打开可查看和继续编辑。增加重复名称、非法请求头和长度校验。
- 方案模板的订阅源配置复用同一组控件；编辑 HTTP 设置保留现有 SSH/代理配置和模板待填字段。
- 获取设置仅来源所有者可读取，加密保存并禁止响应缓存。读取失败、并发修订和过期响应保留恢复与保护流程。

### 升级说明

本版本无数据库迁移变更，保留现有 32 个迁移、数据库、账号、SSH 配置及加密密钥。

通过系统版本菜单检查、准备并重启升级。手动升级使用 `AIRMUX_VERSION=v0.4.6`；已设置 `AIRMUX_APP_IMAGE` 时，替换为附件 `release-manifest.json` 中的 `image` 值。

修改 UA 或请求头后，保存并刷新订阅源，再核对原始数据。来源新内容需重新生成预览并发布方案版本，再刷新客户端订阅；已发布方案文件保持不可变。

### Changes

- Restore saved User-Agent and headers when reopening a URL source for editing.
- Select the server default, Clash or Clash.Meta with the existing searchable dropdown; preserve saved custom agents and migrate a saved User-Agent header into that control.
- Add, edit and delete other headers as Key/Value rows, with duplicate, name and size validation. Reuse the same controls for template sources and preserve transport settings and template placeholders.
- Restrict editable HTTP settings to their source owner, retain encrypted storage and disable response caching. Keep loading, retry, revision-conflict and stale-response safeguards.

No database migration is added. Preserve all 32 existing migrations, your database, accounts, SSH profiles and encryption key. Update through the version menu, or select `v0.4.6` and replace a pinned image using the attached manifest.

After changing HTTP settings, save and refresh the source. Preview and publish a new plan version to use changed source content in client subscriptions. Existing published plan files remain immutable.
