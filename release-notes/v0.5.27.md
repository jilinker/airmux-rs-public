# Air.mux v0.5.27

- Mihomo 功能配置的「独立入站」新增可选重定向端口和 TProxy 端口。分别填写才生成 `redir-port` 或 `tproxy-port`，留空不输出。同一字段的有效值不同时由方案选择来源。
- 在 Mihomo 方案的「路由与 DNS → 策略 DNS 地址」中，可以为域名解析或代理服务器解析策略单独停用地址。每条策略至少保留一个，配置库、其他策略和其他方案不受影响。旧方案及新增引用默认启用。

## 升级说明

从 0.5.26 升级无新增 SQL 迁移。最低升级版本为 0.5.0。**从 0.5.9 之前升级会执行清理迁移，删除旧公共方案、客户端方案、相关归档及全部访问链接。** 升级前请备份数据库并保管原加密主密钥。0.4.x 须独立空库安装。
