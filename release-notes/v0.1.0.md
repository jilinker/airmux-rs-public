Airmux RS 首个可部署版本，提供 Rust API、Vue 管理界面与 Linux amd64 Docker 镜像。

- 账号与管理员权限、用户资源隔离、用户管理和日志详情。
- 订阅源及刷新任务、配置方案和模板、自定义分组与家宽分组。
- 路由、DNS、运行参数、配置预览与版本发布。
- 访问链接的复制、启停、轮换与删除。
- 可配置 GitHub 和镜像仓库的两阶段系统更新，包含备份校验与故障恢复状态。

镜像以 `release-manifest.json` 中的摘要为准，平台为 `linux/amd64`。首次部署必须先迁移数据库并创建管理员；运行时需要独立的加密密钥。参见仓库中的 `docs/DEPLOYMENT.md`。

本版本无需 Redis。部署配置、密钥及本机测试数据不包含在源码或镜像中。
