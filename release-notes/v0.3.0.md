Airmux RS v0.3.0 — 模板资源、统一操作反馈与路由排序 / Template resources, notifications, and routing order

### 更新内容

- 方案模板可保存订阅源与自定义节点预设，复用正式资源表单；敏感凭据使用占位字段，由应用者补齐。
- 从模板创建或向已有方案应用资源时，支持逐项选择、建议选用、复用已有资源与新建副本。默认只追加资源，配置章节须明确选择才替换；模板修改不回写已有方案或历史发布版本。
- 模板应用在同一事务完成资源创建、引用映射、草稿与审计，校验所有权、固定模板版本、ETag 与幂等请求，失败全部回滚。客户端仍在发布方案后才使用变更。
- 成功和失败提示统一显示在右上角，带 5 秒自动关闭进度条，保留错误详情、返回修改和重试；输入内容与焦点持续保留，危险操作继续要求明确确认。
- 订阅源页面分为“订阅源 / 自定义节点”两个 Tab，切换保留搜索、协议筛选和分页状态。模板列表整行悬浮背景包含复制、删除按钮。
- 模板与方案共用组排序、组内排序和完整位置预览；保留其他组槽位、规则字段及停用状态，MATCH / FINAL 固定末尾。
- 来源高级获取支持 UA、请求头、HTTP/HTTPS/SOCKS5 代理与 SSH，设置加密保存；编辑留空保留，显式空对象清除。镜像包含 SSH 客户端。

### 升级说明

镜像架构为 `linux/amd64`，最低支持当前版本 `0.1.2`。本版本新增 `0028_template_resources.sql`，全部 28 个迁移随镜像提供，已发布的前 27 个迁移保持不变。升级前备份数据库；保留现有数据库、`config.yaml` 和加密密钥，无需重新初始化管理员账号。

推荐通过系统版本菜单检查并准备更新，再执行重启升级。手动升级时，将 `.env` 中的 `AIRMUX_VERSION` 改为 `v0.3.0`，然后执行：

```sh
docker compose pull api frontend updater
docker compose up -d --wait
docker compose ps
```

若 `AIRMUX_APP_IMAGE` 已由在线更新固定为镜像摘要，手动升级还需将其替换为本 Release 附件 `release-manifest.json` 中的 `image`。该覆盖值优先于 `AIRMUX_VERSION`。同时更新 api、frontend 和 updater；准备更新不会直接修改业务数据，确认重启后才执行备份与迁移。

### Changes

- Templates now include reusable source and custom-node presets. Credentials use placeholders completed by the applying user, with the existing resource forms reused throughout.
- Create or apply templates with individual resource selection, recommendations, reuse, or explicit copies. Existing plans append resources by default; configuration sections are replaced only when selected. Existing releases remain unchanged.
- Resource creation, reference mapping, draft updates, and audit records share a transaction with ownership, pinned-version, ETag, and idempotency checks. Failure rolls back the complete operation; clients receive changes only after plan publication.
- Success and error notifications appear at the top right with a five-second countdown. Details, retry actions, form values, and input focus are retained; destructive actions still require explicit confirmation.
- Sources and custom nodes use separate tabs that preserve search, protocol filters, and pagination. Template-row hover backgrounds also include action buttons.
- Shared group and within-group sorting includes a full position preview while preserving rule fields, disabled state, unrelated positions, and the final MATCH / FINAL rule.
- Advanced fetching supports UA, headers, HTTP/HTTPS/SOCKS5 proxies, and SSH with encrypted settings and existing address checks. The image includes the SSH client.

### Upgrade

This release targets `linux/amd64` and requires a current version of at least `0.1.2`. It adds migration `0028_template_resources.sql`; all 27 previously released migrations remain unchanged. Back up the database and preserve your configuration and encryption key.

Use the version menu, or set `AIRMUX_VERSION=v0.3.0` and run the Compose commands above. If `AIRMUX_APP_IMAGE` is pinned, replace it with the `image` value in the attached manifest. Update api, frontend, and updater together.
