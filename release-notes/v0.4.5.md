Airmux RS v0.4.5 — 订阅源原始数据与草稿同步 / Source data and live draft updates

### 更新内容

- 订阅源增加「原始数据」弹窗，查看最近一次成功下载或导入保存的完整响应。支持行号、搜索定位、复制和下载；Base64 订阅可切换解码视图，并展示格式、快照修订及当时显式配置的 UA。
- 被方案草稿引用的订阅源允许修改 URL、获取选项、刷新设置、名称及重新导入文件。修复文件来源改名保存失败，保留删除引用保护和并发修订检查。
- 来源修改或刷新后，打开的方案同步最新节点并清除旧预览，保留尚未保存的本地编辑。同源标签页即时通知，前台定时检查后台变化，预览和发布前再次核对。
- 原始内容仅来源所有者可访问，响应禁止缓存；读取已保存的快照，不重新访问上游订阅。

### 升级说明

本版本无需新增数据库迁移。保留现有 32 个迁移、数据库、账号、SSH 配置及加密密钥。

通过系统版本菜单检查、准备并重启升级。手动升级使用 `AIRMUX_VERSION=v0.4.5`；已设置 `AIRMUX_APP_IMAGE` 时，替换为附件 `release-manifest.json` 中的 `image` 值。

已发布方案文件保持不可变。来源更新后，重新生成预览并发布新方案版本，再刷新客户端订阅；固定版本的访问链接需切换版本或改为跟随最新版。

### Changes

- Inspect the complete saved subscription response in a reusable dialog with line numbers, search, copy and download. Base64 subscriptions include a decoded view, input format, snapshot revision and the explicitly configured User-Agent at retrieval time.
- Allow editing and reimporting sources referenced by drafts. Fix file-source rename failures while retaining deletion protection and revision checks.
- Update open drafts when sources change, invalidate stale previews and preserve unsaved edits. Notify same-origin tabs, check background changes periodically in the foreground, and recheck before preview or publication.
- Restrict raw snapshot access to its owner and disable response caching. Viewing a snapshot does not download the subscription again.

No database migration is added. Preserve all 32 existing migrations, your database, accounts, SSH profiles and encryption key. Update through the version menu, or select `v0.4.5` and replace a pinned image using the attached manifest.

Published plan files remain immutable. Preview and publish a new plan version after source updates, then refresh the client subscription. Pinned links must select the new version or follow the latest release.
