# Airmux RS v0.5.2

本次将目录和方案来源节点维护改为数据库真实分页，统一查询契约，并保留跨页编辑状态。

## 列表与分页

- 节点、公共方案、客户端方案、访问链接、规则集、用户目录及方案来源节点维护抽屉均由后端筛选、排序、统计总数并读取当前页。
- 分页接口统一使用 `page`、`size`，返回 `items`、`total`、`page`、`size`，便于分页组件复用。
- 筛选和容量变化回到首页，删除末页记录后回到有效页，快速搜索时迟到响应不会覆盖新结果。
- 表头宽度和跨页节点启用、地区草稿保留，客户端方案直接显示关联公共方案名称。
- 节点服务器地址搜索保留，连接密码与协议认证材料继续加密存储。

## 安装与升级

- 目标镜像为 `docker.io/jaelinker/airmux:v0.5.2`，正式平台为 `linux/amd64`，发行附件清单提供固定摘要。
- 最低可升级版本为 **0.5.0**，数据库代际保持 `plan-local-v1`，旧 `0.4.x` 仍需独立空库安装。
- 仅追加 `0011_node_search_server.sql`，不改写已发布迁移。更新时保留原数据库、程序加密主密钥、SSH 主机记录和更新器状态。
- 新增服务器域名或地址的搜索投影，不包含密码或协议认证材料。首次启动监听前使用原密钥分批回填历史节点，节点业务版本保持原值；旧库节点越多，首次启动回填所需时间越长。
- 使用系统更新入口准备镜像，再在维护时间重启。失败时保留备份、原密钥和更新状态，按部署指南恢复，不删除迁移历史绕过校验。

## 验证范围

分页改造已通过 Rust 工作区 107 项、隔离数据库 36 项、前端 228 项回归，以及接口类型生成、类型检查、生产构建和原型构建。数据库测试覆盖所有者隔离、筛选总数、字面特殊字符、稳定排序、越界回退、跨页草稿和历史搜索字段回填。

Python 55 项回归及 PostgreSQL 17 的 36 项隔离数据库回归通过。正式候选镜像已完成三文件模板空库安装、首次改密、分页接口和静态资源检查。

使用正式 `0.5.1` 镜像与合成数据完成更新器升级：十条迁移增至十一条，35 个历史节点的搜索投影全部回填，服务器搜索第二页正确返回 5 条。另一个隔离库注入字段冲突，确认 SQL 失败后进入 `needs_recovery` 并停止 API。成功与失败流程各自生成的备份均恢复至独立库，十四张核心表数据一致，正式 `0.5.1` 服务恢复就绪。

Mihomo v1.19.33 的四个固定参考用例通过原生检查，其中无效配置按预期拒绝。本轮未做浏览器实屏验收，Loon 按既有要求继续暂缓验证；未操作用户部署或业务数据库。
