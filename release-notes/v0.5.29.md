# Air.mux v0.5.29

修复替换基础配置后，取消失效地区组仍然无法保存方案的问题。

- 在「方案 → 编辑 → 分组成员」取消失效地区并应用后，真正移除旧引用，不再将它作为未选中记录提交。
- 保留有效地区的排除选择、未启用家宽的记录，以及节点与内置策略顺序。仍被选中的失效项继续提示处理，不按名称自动换绑。
- 新发现失效地区成员时自动进入分组成员分区，校验错误指出手动组名称与成员位置。

## 升级说明

从 0.5.28 升级无新增 SQL 迁移，沿用十五份历史迁移。旧方案不被自动重写；出现提示时，取消失效项并应用，再保存方案。

从 0.5.27 或更早版本升级仍会执行功能 DNS 的第十五份迁移，须保留原加密主密钥，且被引用的基础 DNS 来源必须完整、无歧义。升级前请备份数据库。

最低升级版本为 0.5.0。**从 0.5.9 之前升级会执行历史清理迁移，删除旧公共方案、客户端方案、相关归档及全部访问链接。** 0.4.x 须独立空库安装。Loon 原生与实机验收继续暂缓。
