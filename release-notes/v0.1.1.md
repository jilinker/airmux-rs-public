Airmux RS v0.1.1 — 公共发行与免配置更新检查 / Public releases and update checks

- 源码继续保留在私有仓库；发行版本、部署文档与脱敏截图统一发布到 `jilinker/airmux-rs-public`。
- 系统更新固定读取公共 Release，不再需要 GitHub 仓库地址或 GitHub Token；旧仓库配置不会将更新请求导向私有源码仓库。
- 镜像仓库仍可通过 Compose 配置，保持镜像摘要、平台校验、管理员权限和数据库备份流程。
- 提供中英文部署指南和安全发行同步工具，公共 Git 历史只包含文档、部署示例和发行元数据。

Source code remains private. Releases, deployment guides, and redacted screenshots are published in `jilinker/airmux-rs-public`. Update checks use the public repository without a GitHub token or repository setting. Image repository configuration, digest/platform validation, administrator authorization, and database backup protections remain in place.

平台 / Platform: `linux/amd64`. 使用附件 `release-manifest.json` 中固定摘要的镜像。API、前端及更新服务均包含在此镜像中；从 v0.1.0 升级时，部署者还需将独立固定的 `AIRMUX_UPDATER_IMAGE` 更新为本版本镜像并重建 updater，以启用公共更新来源。已有加密密钥和数据库应保持原样。

Use the digest-pinned image in `release-manifest.json`. When moving from v0.1.0, also pin `AIRMUX_UPDATER_IMAGE` to this release and recreate the updater service to enable public update checks. Preserve the existing encryption key and database.
