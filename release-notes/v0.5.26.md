# Air.mux v0.5.26

基础配置、功能配置和方案现在都可以在列表中改名复制。副本和关联由服务端一次创建，成功后刷新当前页。重名时保留输入，可以直接改名重试。

- 配置副本默认私有，规则正文和托管节点独立保存，原本复用的节点保持引用。
- 方案副本保留成员、排序、出口和冲突选择，继续引用同一组配置包、来源和节点，不复制访问链接。

## 升级说明

从 0.5.25 升级没有新增 SQL 迁移。最低升级版本为 0.5.0。**从 0.5.9 之前升级会执行清理迁移，删除旧公共方案、客户端方案、相关归档及全部访问链接。** 升级前请备份数据库并保管原加密主密钥。0.4.x 须独立空库安装。
