Airmux RS v0.4.7 — 规则集名称与 Loon 复制转换 / Named rule sets and Loon copy conversion

### 更新内容

- 生成配置中的规则集使用可读名称，内部关联继续使用 ID；新增规则集名称唯一校验，统一处理重名与名称冲突。
- 方案和方案模板共用复制入口，可将 Mihomo 复制为 Mihomo 或 Loon，保留原对象；Loon 支持同类型复制。
- 规则集管理统一提供 Loon 兼容转换。转换检查完整规则文件，支持可兼容的域名和 IP 规则格式，转换失败不会返回部分成功内容。
- 复制后提供转换报告、定位、重新检查和舍弃操作。不等价或不支持的配置保留待处理，处理完成前不能预览、发布或采用模板，避免静默丢失路由语义。
- Loon 规则集下载沿用方案访问控制与当前库内容；不兼容的新内容返回明确错误。Loon 使用原生更新机制，不额外生成未经支持的下载间隔参数。

### 升级说明

新增数据库迁移 `0033_template_conversion.sql`，保留已发布的 32 个迁移、数据库、管理员、SSH 配置与加密密钥。请通过系统版本菜单检查、准备并重启升级，准备阶段会备份数据库。

手动升级使用 `AIRMUX_VERSION=v0.4.7`；已设置 `AIRMUX_APP_IMAGE` 时，使用附件 `release-manifest.json` 中的固定镜像地址。

已有发布方案保持不可变；需要采用新名称或转换结果时，请重新生成预览并发布新方案版本。转换报告仍会对 IP/no-resolve、规则顺序、DNS 或下载出站等无法证明等价的配置提示处理。当前已完成自动化及浏览器验证，尚未进行 Loon 真机验证。

### Changes

- Render readable, collision-safe rule-set names while retaining internal IDs; validate name uniqueness.
- Copy plans and templates to Mihomo or Loon through the shared copy flow, preserving the original. Loon supports same-target copying.
- Convert complete compatible rule-library files for Loon with strict validation and no partial-success downloads.
- Review, locate, recheck or discard conversion findings. Unresolved compatibility issues block preview, publication and template adoption.
- Keep authenticated plan-scoped rule downloads and validate current library content. Use Loon's native update behavior without inventing interval parameters.

This release adds migration `0033_template_conversion.sql`; all 32 published migrations remain unchanged. Preserve your database, accounts, SSH profiles and encryption key. Update through the version menu or use the pinned image in the attached manifest. Existing published artifacts remain immutable. Loon device testing has not been performed; review any compatibility findings before publishing converted plans.
