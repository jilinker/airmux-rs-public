Airmux RS v0.1.3 — 三文件 Compose 部署 / Three-file Compose deployment

部署简化为三个步骤：

1. 从公共仓库下载 `config.yaml` 和 `compose.yaml`，按中文注释修改配置。
2. 下载 `.env`，填写相同数据库密码，按需调整镜像、端口或目录，执行 `docker compose up -d --wait`。
3. 用 `docker compose ps` 和 `docker compose logs --tail=50 api` 检查，再访问页面登录。

无需克隆仓库、安装 Python、执行管理脚本或下载 nginx 配置。数据库迁移与首次管理员初始化仍由 Rust 启动自动完成。镜像公开可匿名拉取，架构为 `linux/amd64`。

更新程序直接使用 `.env`，更新镜像时保留用户设置与密码；已有 `.compose.env` / `runtime.env` 部署保持兼容。已有安装必须保留数据库与原加密密钥，无需重新初始化。

Download `config.yaml`, `compose.yaml`, and `.env` from the public repository, edit the documented settings, start with `docker compose up -d --wait`, then check services and sign in. No clone, host Python, management script, or external nginx file is required. Rust initializes the database and first administrator automatically. The updater supports the new `.env` layout while preserving the previous generated environment layout. Existing deployments retain their database and encryption key.
