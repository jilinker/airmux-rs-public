# Airmux RS v0.5.9

方案改为组合一份基础配置和多份功能配置，配置可复用、共享并导入为独立副本。

## 升级前必读

**本版本会清空旧公共方案、客户端方案、相关归档及全部访问链接，不迁移或兼容旧方案，原链接失效。** 这是统一方案模型的明确重构边界。账号、节点来源、节点、管理员地区和规则集、系统配置及历史迁移保留。升级前备份数据库并保管原加密主密钥，升级后重新创建配置、方案及访问链接。

- 镜像 `docker.io/jaelinker/airmux:v0.5.9`，支持 `linux/amd64`。固定摘要和真实源码提交见发行附件。
- 最低升级版本 **0.5.0**，数据库代际 `plan-local-v1`。仅追加 `0013_composed_schemes.sql`，前十二份 SQL 不变。
- 需要恢复旧方案时，将升级前备份恢复到独立数据库，使用原加密主密钥及旧版镜像。旧 `0.4.x` 仍须独立空库安装。

## 配置组合与共享

- 菜单统一为「方案」「配置库」「我的共享」，基础配置与功能配置在同页切换。每份配置维护一个手动主组，方案固定 Mihomo 或 Loon 类型。
- 方案保留动态订阅源、节点启停、人工地区和手工节点选择；成员、跨配置顺序、出口和最终兜底由方案决定。地区节点通过地区组选择，直选节点单独选择。
- 配置实时引用；同名不同内容展示来源和差异，由方案明确选择。配置更新集中确认全部受影响方案，取消不写入，确认后原子保存。语义变化重新确认，新增条目明确安排顺序。
- 功能配置支持规则集、路由、DNS 解析器与策略、Fake IP 条目、强制嗅探域名及托管手工节点。Mihomo 功能配置也可添加独立入站，同名或地址端口冲突时选择来源。
- 共享发现按用户名与配置查找，导入成为自己的独立副本。「我的共享」仅编辑共享设置，内容与配置库同步。认证材料需明确许可，不公开时保留结构及待绑定项。用户名全站唯一，默认邮箱，可自定义一次。
- 分页刷新统一为分页栏最右侧图标，保留筛选、页码、容量、列宽及选择，不触发订阅刷新或规则同步。两级页签与抽屉布局同步整理。

## 验证范围

Rust 工作区 122 项、前端 284 项、隔离 PostgreSQL 35 项及 Python 55 项回归通过，格式、契约生成、类型检查、生产和原型构建通过。组合产物已通过 Mihomo v1.19.33 原生检查。最终镜像通过三文件空库安装、十三份迁移摘要核对、七个默认地区、首次改密及真实接口组合保存重读与生成检查。从正式 0.5.8 完成正常升级、迁移执行器失败停机及两份备份的独立恢复；恢复后旧版 HTTP 可读取三十五个合成节点和旧方案并生成配置。Loon 本轮继续暂缓原生与实机验证，未做真实代理流量测试；不操作用户部署或业务数据库。
