Airmux RS v0.1.2 — 首次安装与统一配置 / First installation and unified configuration

- Docker Compose 负责部署，`config.yaml` 只读挂载到 API 和更新程序；应用运行参数集中在同一文件。
- Rust 启动自动执行全部待执行 SQLx 迁移并校验记录。迁移元数据固定在 `public` schema，避免数据库用户名为 `airmux` 时的重启异常；报错时释放会话锁。
- 按配置初始化首个管理员，并使用事务锁防止重复创建。已有管理员的密码、角色和状态不会被覆盖；首次登录必须修改初始密码。
- 安装辅助工具生成数据库密码、加密密钥与更新凭据，渲染 Compose 参数；已有配置拒绝覆盖。中英文部署指南以 Compose 命令为主。
- 复用已有 Docker PostgreSQL 时不创建额外数据库服务；保留原加密密钥、数据与更新备份状态。

Compose orchestrates deployment and mounts `config.yaml` read-only into the API and updater. Rust applies pending SQLx migrations, verifies history in the fixed `public` schema, and initializes the first administrator under a transaction lock. Existing accounts are preserved. Installation tools generate strong credentials and Compose parameters without overwriting existing configuration. Bilingual deployment guides now use Compose as the main entry point.

**升级说明 / Upgrade:** v0.1.1 及更早版本需先备份并将旧环境配置迁移到新的 `config.yaml`，保留原数据库和加密密钥，然后按部署指南手动切换镜像。本版设置 `minimumVersion: 0.1.2`，阻止旧配置环境直接在线升级到不兼容的运行配置。

For v0.1.1 or earlier, back up first, move the existing runtime settings into `config.yaml`, preserve the original database and encryption key, then switch images using the deployment guide. `minimumVersion: 0.1.2` prevents older configurations from upgrading online without this conversion.

平台 / Platform: `linux/amd64`. API、前端和更新程序使用发行清单中固定摘要的同一个镜像。
